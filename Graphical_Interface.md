\# ST7789 TFT LCD Screen (Chinese model, GM020-02)



link:https://goldenmorninglcd.com/tft-display-module/2-inch-240x320-st7789v-gmt020-02/



\## The screen uses the Adafruit Core GFX library for shapes, texts and possibly bitmapping



\## A Graphical menu Interface that can be interacted by three buttons:

\-To wake the device up and start main process (look at README.md)

\-Change options

\-Select



To get a responsive interface, especially as it shares the same spi bus with the RFID reader, by enabling and disabling the devices through their SS pins (slave select), to make room when handling resource must be considered.



Bitmaps(.bmp) and ASCII art(.txt?) can be stored through the SD card and is loaded before the page it is used.
